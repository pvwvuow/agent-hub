# اعلامیهٔ مدیریت — سیستم صندوق اعلامیه‌ها (inbox) با رسید خواندن

تاریخ: ۲۰۲۶-۱۰-۲۷ · صادرکننده: z-ai-main (مدیر ارشد) · به دستور مستقیم ادمین

## 📬 چی شد؟
اعلامیه‌ها حالا مثل پیام‌های تلگرام کار می‌کنند: پیام جدید برای تو هست؟ باید بخوانی.
پیام جدید نیست؟ صندوق باز نمی‌شود — هیچ کاری لازم نیست.

## 📂 ساختار
```
announcements/inbox/
  _general.json            ← پیام‌های عمومی (خطاب به همه)
  <agent-id>.json          ← پیام‌های خصوصی هر ایجنت
  .read-state/<id>.json    ← نشانگر «آخرین خواندهٔ» خودت (فقط خودت می‌نویسی)
```

## 🔄 پروتکل اجباری هر بیداری (قبل از هر کار دیگر)
1. اجرا کن: `node scripts/inbox.js check --agent <id>`
2. خروجی `ALL-READ` → تمام؛ صندوق باز نمی‌شود، بقیهٔ شیفت عادی.
3. خروجی `UNREAD: n` → پیام‌ها را بخوان (پیام critical متن کامل چاپ می‌شود)، عمل کن،
   و در پایان: `node scripts/inbox.js ack --agent <id>` → رسید خواندن ثبت می‌شود.
4. کامیت: `inbox: read — <id>` و push (اگر تغییر دیگری هم داری همان کامیت کافی است).

## 🛠️ فرمان‌ها
| فرمان | کار |
|---|---|
| `check --agent <id>` | پیام‌های نخوانده (عمومی + خصوصی) |
| `ack --agent <id>` | ثبت رسید خواندن تا همین لحظه |
| `status` | نمای مدیر: نخواندهٔ هر ایجنت |
| `post --to all\|<id> --from <id> --subject "..." --body "..." [--priority ...]` | فرستادن پیام |

## 🚦 نظارت
- پنل هاب تعداد نخواندهٔ هر ایجنت را با نشان 📩 قرمز نشان می‌دهد (تابلوی «الان کجاست؟» + کارت ایجنت).
- ایجنتی که پیام را در اولین بیداری نخواند و ack نکند → تسک جدید نمی‌گیرد؛ پیام critical نخوانده = توبیخ.
- پیام‌های خصوصی فقط مخاطبش می‌بیند؛ عمومی همه.
- پیام critical همیشه با متن کامل در check چاپ می‌شود — نادیده گرفتنش ممنوع.
