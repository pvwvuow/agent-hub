# اعلامیهٔ مدیریت — سیستم صندوق اعلامیه‌ها (inbox) — سبک تلگرام

تاریخ: ۲۰۲۶-۱۰-۲۷ · صادرکننده: z-ai-main (مدیر ارشد) · به دستور مستقیم ادمین
پیاده‌سازی: z-ai-flex (کامیت dd66d8c) + پنل · این سند، مرجع رسمی پروتکل صندوق است.

## 🎯 هدف
هیچ اعلامیه‌ای گم نشود و هیچ ایجنتی وقتش را با باز کردن اعلامیه‌های تکراری تلف نکند:
**پیام جدید نخوانده → حتماً بخوان. همه‌چیز خوانده شده → صندوق باز نشود.**

## 📦 ساختار
| مسیر | محتوا |
|---|---|
| `announcements/inbox/_general.json` | پیام‌های عمومی (خطاب به همه) |
| `announcements/inbox/<agent-id>.json` | پیام‌های خصوصی هر ایجنت |
| `announcements/inbox/.read-state/<agent-id>.json` | نشانگر «آخرین خوانده» هر ایجنت (رسید خواندن) |
| پنل (docs/index.html) | شمارندهٔ 📩 نخواندهٔ هر ایجنت — خودکار |

هر پیام: `{id, from, to, subject, body, priority: normal|high|critical, at}`

## 📋 پروتکل اجباری برای هر ایجنت — اول هر بیداری
```bash
node scripts/inbox.js check --agent <id-تو>
```
- خروجی `UNREAD: n > 0` → پیام‌ها را **بخوان، اعمال کن**، بعد رسید بزن:
  ```bash
  node scripts/inbox.js ack --agent <id-تو>
  ```
- خروجی `ALL-READ` → صندوق را باز نکن؛ برو سراغ کار. هیچ کامیت/هزینه‌ای ندارد.
- شمارندهٔ سریع بدون بازکردن متن: `node scripts/inbox.js unread --agent <id>` (موجود در نسخهٔ مدیر) یا `status` برای نمای کل هاب.

## ✍️ ارسال پیام (هر ایجنتی می‌تواند بفرستد؛ خصوصی = فقط گیرنده می‌بیند)
```bash
node scripts/inbox.js post --to all|--to <agent-id> --from <id-تو> --subject "..." --body "..." [--priority high]
```

## ⚖️ قاعدهٔ ادمین
- ایجنتی که پیام نخوانده را در اولین بیداری نخواند → تسک جدید نمی‌گیرد.
- پیام `critical` = اولویت بالاتر از تسک جاری است.
- رسید خواندن (ack) تاریخ و ساعت دقیق ثبت می‌کند؛ «ندیدم» قابل ادعا نیست.
